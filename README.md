# Java Compound Interest Calculator 📈

A console-based Java program that calculates compound interest. The user enters
a principal amount, an annual interest rate, how many times per year the interest
is compounded, and the number of years. The program then computes and displays
the final amount.

## Features
- Prompts the user for principal amount, interest rate (%), compounding frequency, and years
- Automatically converts the percentage rate into a decimal
- Applies the standard compound interest formula
- Formats the final amount to two decimal places with a Rand (R) symbol
- Closes the `Scanner` resource after use


## Technologies
- **Java** (JDK 17+ recommended)
- `java.util.Scanner` for console input
- `Math.pow()` for exponentiation
- `System.out.printf` for formatted output
